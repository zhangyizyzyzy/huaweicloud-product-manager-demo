## 简介

单文件、零依赖的纯前端商品管理应用，对应华为云云实验《基于 CodeArts 代码智能体-快速构建商品管理 Web 应用》的核心实践。全部样式与脚本位于 `index.html`，无需构建工具或后端服务。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 添加 | 录入名称、数量、单价，校验后加入列表 |
| 编辑 | 行内修改后保存，更新小计与合计 |
| 删除 | 二次确认后删除商品 |
| 搜索 | 按名称实时模糊匹配 |
| 校验 | 名称不能为空；数量为非负整数；单价为非负数且不超过 99999999 |
| 本地保存 | 使用浏览器 localStorage 持久化 |
| 汇总 | 计算当前匹配列表的数量及金额合计 |

## 使用方法

1. 下载 `index.html`，用现代浏览器打开，也可在 CodeArts 产物预览中查看。
2. 首次打开自动载入 3 条演示数据。
3. 在顶部填写名称、数量、单价，点击“添加”。
4. 在列表中编辑并保存，或确认删除。
5. 搜索框可按名称过滤。变更自动保存在当前浏览器中。

技术栈：原生 HTML、CSS、JavaScript；使用 `Number.isInteger`、`Array.find`、`Element.closest` 等现代 API。存储键名为 `codearts_product_list`。无 npm 包、CDN 或外部 API。

## 已知限制

- 删除全部商品后刷新，会重新生成 3 条演示数据。
- 搜索时数量及金额合计按当前匹配列表计算，商品种类总数仍显示全部商品数。
- localStorage 不可替代数据库、备份及访问控制；清理浏览器数据会丢失记录。
- 金额使用 JavaScript 浮点数计算，不适用于真实财务结算。
- 示例云产品名称与价格仅作演示，不代表官方报价。
- 商品名称在拼接 HTML 时经过 `escapeHtml` 转义，但项目未做生产级安全加固。

应用本身不上传商品数据，不调用付费 API，不依赖云资源。请勿存放真实业务或敏感数据。
